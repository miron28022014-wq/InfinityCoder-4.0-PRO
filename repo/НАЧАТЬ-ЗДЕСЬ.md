# InfinityCoder 4.0 — с чего начать

## Хочу просто запустить и посмотреть

Нужен Node.js 22.5+.

```bash
./scripts/install.sh          # установка (Linux/macOS)
powershell -ExecutionPolicy Bypass -File scripts\install.ps1   # Windows
./scripts/start.sh            # запуск
```

Откройте <http://127.0.0.1:8090>.

Быстрый вариант без установки:

```bash
npm install
npm run build
npm run serve
```

Подробности — в [docs/QUICKSTART.md](docs/QUICKSTART.md).

## Хочу собрать установщик для Windows (десктоп, Tauri)

Нужен компьютер с Windows и Rust с MSVC:

1. **Node.js 22.5+** — <https://nodejs.org>
2. **Rust** — `winget install Rustlang.Rustup` или <https://rustup.rs>
3. **Visual Studio Build Tools** с компонентой «Desktop development with C++»

Затем:

```powershell
npm install
npm run tauri:build
```

Готовые установщики появятся в `src-tauri/target/release/bundle/`
(`.msi` для NSIS/MSI и `.exe`).

> В среде, где велась разработка 4.0, Rust-инструментов не было, поэтому
> десктопные бинарники не собирались. Веб-путь (`scripts/install.sh`) проверен
> полностью: установка, сборка, миграции, запуск.

## Хочу подключить экосистему

```bash
npm run ecosystem:build     # собрать Core API
npm run ecosystem:migrate   # миграции БД
npm run ecosystem:start     # ядро на :8787
```

В IDE: панель **«Экосистема»** (рельса слева) → адрес `http://127.0.0.1:8787` →
**Подключить** → вход через Infinity ID.

Контракт с ядром — [docs/ECOSYSTEM.md](docs/ECOSYSTEM.md).

## Хочу узнать про автономность

Раздел **«Автономность»** в настройках: агент сам продолжает незакрытую задачу
и не переспрашивает на безопасных операциях. Разрушительные действия и запреты
экосистемы по-прежнему требуют вашего решения.
