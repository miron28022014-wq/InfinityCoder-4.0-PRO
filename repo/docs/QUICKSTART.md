# Быстрый старт InfinityCoder 4.0

Пять минут от установки до первой задачи, которую агент доведёт сам.

## 1. Запуск

```bash
./scripts/start.sh
```

Откройте <http://127.0.0.1:8090>.

## 2. Открыть проект

Нажмите **«Открыть проект»** на стартовом экране (или кнопку папки в заголовке).
В десктопной сборке откроется системный диалог, в веб-режиме откроется виртуальная ФС
браузера. Дальше всё одинаково.

Проводник слева раскрывает корень сразу — файлы уже видны.

## 3. Модель

Пока не настроена модель, композер не примет задачу. Два пути:

### Путь A — локально, без сети (рекомендуется для начала)

1. Поднимите llama.cpp-совместимый сервер на `127.0.0.1:8080`.
2. **Настройки → Модель → Провайдер: локальный**, укажите имя модели.
3. Проверка статуса в правом верхнем углу должна стать зелёной.

### Путь B — через ядро экосистемы

1. Поднимите Core API: `npm run ecosystem:start` в каталоге установки.
2. **Настройки → Экосистема** → адрес `http://127.0.0.1:8787` → **Подключить**.
3. Войдите через Infinity ID (панель «Экосистема» слева).
4. В **Настройки → Модель** включите «Использовать экосистему» и выберите модель из списка.

Ключи провайдеров в этом режиме хранит сервер — в IDE они не появляются.

## 4. Первая задача

Напишите в композер, например:

> Изучи структуру проекта и объясни архитектуру

Агент:

1. построит план (Архитектор);
2. прочитает файлы (`read_file`, `search_files`);
3. даст ответ;
4. **проверит** сам себя вторым проходом и, если ответ неполный, продолжит работу.

Если выключить «Проверять и чинить результат» в настройках, шага 4 не будет.

## 5. Автономный режим

Включён по умолчанию. Что он меняет:

* агент **не спрашивает** подтверждения на безопасных операциях (правки файлов, чтение,
  запуск команд);
* если агент остановился, не доведя задачу до конца, движок **подтолкнёт его продолжить**;
* разрушительные операции (удаление файлов, опасные команды) и `deny`-гранты экосистемы
  по-прежнему спрашивают.

Переключатели: шапка панели агента (чип «Автономный»), композер (чип «авто»),
**Настройки → Автономность**.

## 6. Подключить экосистему (по желанию)

Панель «Экосистема» в рельсе слева:

* **Infinity ID** — вход и профиль;
* **Модель и режим** — какая модель и локальный режим или облако;
* **Разрешения инструментов** — гранты `ask` / `allow` / `deny` от ядра;
* **Поиск по экосистеме** — Notes, Drive, история, память;
* **Обмен с приложениями** — сохранить отчёт в Infinity Notes;
* **Sync** — журнал изменений и курсор синхронизации.

Права всегда проверяются на сервере: даже если интерфейс показывает разрешение, ядро
может отклонить вызов.

## Горячие клавиши

| Действие | Клавиши |
|---|---|
| Палитра команд | `Ctrl`/`⌘` + `K` (или `P` — файлы) |
| Сохранить всё | `Ctrl`/`⌘` + `S` |
| Остановить агента | `Esc` |
| Отправить задачу | `Ctrl`/`⌘` + `Enter` (в композере) |
| Перенос строки | `Shift` + `Enter` |
