# Changelog

## 4.0.0 — 2026-10-23

База: **InfinityCoder 3.0** (Tauri + React + Vite + Tailwind + CodeMirror).
Основание доработки — требования по «максимальному апгрейду» и полной интеграции
Infinity Ecosystem.

### Интерфейс — полный редизайн

* **Новая дизайн-система** (`src/index.css`): глубокая сине-графитовая палитра, приподнятые
  и стеклянные поверхности, акцент-градиент синий→фиолетовый, переработанная светлая тема,
  обновлённые радиусы, тени и типографическая шкала (базовый кегль 13.5 → 14 px).
* **Рельса действий** (`src/components/shell/ActivityRail.tsx`): навигация Файлы / Агенты /
  Память / Экосистема переехала из вкладок в вертикальную рельсу с активным индикатором,
  подсказками и счётчиками.
* **Стартовый экран** (`src/components/shell/StartScreen.tsx`): вместо пустого редактора —
  hero с описанием возможностей, тремя главными действиями и честным объяснением, что
  проекта ещё нет.
* **Панель агента**: новая шапка со статусом модели и переключателем автономности,
  переработанная лента сообщений, карточки инструментов с цветовой семантикой по статусу.
* **Композер**: оформлен как командная строка с быстрыми подсказками, чипами режима,
  усилия и роли, тумблерами плана/проверки/памяти/автономности.
* **Проводник**: корень проекта раскрывается сразу после открытия, заголовок панели
  показывает активный раздел.
* **Пустые состояния**: единый компонент с крупной градиентной иконкой.

### Автономность

* Новая настройка `autonomous` (вкл. по умолчанию) и `autonomousNudges` (0…3, по умолчанию 2).
* `src/lib/engine.ts`: если агент завершил ход, но задача не закрыта (маркеры незавершённости
  в тексте либо ни одного вызова инструмента), движок подталкивает агента продолжить работу.
* Политика подтверждений в автономном режиме понижается с «перед каждым действием» до
  «только опасные операции». `deny`-гранты экосистемы и разрушительные операции по-прежнему
  требуют решения пользователя.
* Раздел «Автономность» в настройках, переключатели в шапке агента и в композере.

### Infinity Ecosystem

* `src/lib/ecosystem.ts` — типизированный клиент Core API: Identity, модели и провайдеры,
  completions, гранты, поиск и объекты, память, Sync, диагностика.
* `src/lib/ecosystem-llm.ts` — транспорт генерации через AI Runtime ядра; ключи провайдеров
  не покидают сервер.
* Новые инструменты `ecosystem_search`, `ecosystem_remember`, `ecosystem_object`
  (в `src/lib/tools.ts`, разрешены в `src/lib/agents.ts`).
* `src/lib/engine.ts` — маршрутизация транспорта (локальный / облако / экосистема), исполнение
  грантов `deny`/`allow`, авто-подсказки из общей памяти, запись фактов в общую память.
* `src/lib/prompts.ts` — раздел про экосистему в системном промпте.
* `src/components/ecosystem/EcosystemPanel.tsx` — панель подключения: адрес Core API, вход
  Infinity ID, модель и режим маршрутизации, гранты, поиск по данным экосистемы, Sync,
  диагностика.
* Состояние и настройки экосистемы в `src/store.ts` и `src/lib/settings.ts`.

### Ядро экосистемы (Core API)

* `POST /api/v1/ai/completions` — stateless SSE-completion с историей от клиента,
  маршрутизацией по модели и режиму и блокировкой `LOCAL_MODE_BLOCKED`.
* CORS в `packages/core/src/http/router.ts` (`CoreConfig.corsOrigins`, `INFINITY_CORS_ORIGINS`).
* Модуль `packages/core/src/coder/` и веб-клиент `apps/infinitycoder/`.
* Тесты ядра: 62/62, e2e 16/16 + 13/13 + 22/22.

### Поставка

* `scripts/install.sh` (Linux/macOS) и `scripts/install.ps1` (Windows): установка зависимостей,
  сборка веб-IDE и sidecar-ядра, генерация `.env` с мастер-ключом, миграции, регистрация
  служб.
* `scripts/start.sh` / `start.ps1` / `stop.sh` / `stop.ps1` — запуск и остановка связки
  Core API + мост + веб-IDE.
* `scripts/serve-dist.cjs` теперь проксирует `/api` на терминальный мост — веб-режим получил
  настоящие команды.
* `scripts/screenshots.mjs` — снимает реальный интерфейс через Puppeteer.
* Core API входит в дистрибутив как sidecar в папке `ecosystem/`.

### Исправлено

* `packages/core/src/coder/workspace.ts` — типы `Dirent` вместо `Awaited<ReturnType<…>>`:
  сборка ломалась на свежих `@types/node`.
* Race при разборе `SearchService` — устранён через явный `dispose()`.

### Проверено

* `npm run typecheck` — без ошибок.
* `npm test` — `parse.test.mts` + `ecosystem.test.mts` (28 проверок клиента Core API), 0 падений.
* `npm run build` — сборка без ошибок.
* Установщик: чистая установка в отдельный каталог, сборка, миграции, запуск.
* Скриншоты реального интерфейса: `screenshots/`.

### Не реализовано

* Десктопные бинарники Tauri (`.msi`/NSIS) — в окружении сборки нет Rust-инструментов.
* Сопряжение устройств (Connect) и канал Link.
* Серверные проекты InfinityCoder в экосистеме — модуль ядра есть, UI-интеграция не завершена.
