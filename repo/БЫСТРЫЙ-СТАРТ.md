# InfinityCoder 4.0 — быстрый старт

Короткая версия. Полная — в [docs/QUICKSTART.md](docs/QUICKSTART.md).

```bash
./scripts/install.sh     # или scripts\install.ps1 на Windows
./scripts/start.sh
```

→ <http://127.0.0.1:8090>

1. **«Открыть проект»** на стартовом экране.
2. **Настройки → Модель**: локальный провайдер или ядро экосистемы.
3. Напишите задачу в композере — агент составит план, сделает работу и проверит себя.

Автономный режим включён по умолчанию: агент не бросает задачу на полпути
и не переспрашивает на безопасных операциях.
